# 筛数法

## 1.埃氏筛法

埃氏筛主要思想是先构造一个标记数组`flag`

其值全为`false`，表示一开始所有数全部都是质数

之后从2开始，如果当前数`i`对应的标记`flag[i]`的值为`false`，则将其添加入`prim`中

之后对于当前数`i`，从`2 * i`开始枚举`i`的倍数，直到给定的范围`n`为止，将其所有的倍数的标记均改成`true`

埃氏筛的时间复杂度为`O(n * log(logn))`

代码如下：

```cpp
void e_solve() {
    vector<ll> prim; 
    bool flag[1000] = {false};
    for(ll i = 2; i < 1000; i++) {
        if(flag[i] == false) {
            prim.push_back(i);
        }
        for(ll j = i * 2; j < 1000; j += i) {
            flag[j] = true;
        }
    }
}
```

## 2.欧拉筛法

埃氏筛的缺陷在于有些数被重复改变标记，如果想每个合数的标记只改变一次，可以用欧拉筛（也称线性筛）

欧拉筛的思想是：对于每一个合数`i`，其一定找出一个最小的质因子（即可以从其分解出的因数中找出最小的一个质数），只要让这个合数被它的最小质因子标记一次即可

代码如下：

```cpp
void E_solve() {
    vector<ll> prim;
    bool flag[1000] = {false};
    for(int i = 2; i < 1000; i++) {
        if(flag[i] == false) {
            prim.push_back(i);
        }
        for(int j = 0; i * prim[j] < 1000; j++) {
            flag[i * prim[j]] = true;
            if(i % prim[j] == 0) {
                break;
            }
        }
    }
    for(int i : prim) {
        cout << i << endl;
    }
}
```
