二分查找的模板：

给定一个只增不减的序列a，查找不大于number的最后一个数

```cpp
#include <iostream>
#include <vector>
using namespace std;
vector<int> a;
int n;
int number;
int b_find(int need_find) {
    int l = 0, r = n + 1;
    while(l + 1 < r) {
        int middle = (l + r) / 2;
        if(a[middle] <= need_find) {
            l = middle;
        }
        else {
            r = middle;
        }
    }
    return l;
}
void solve() {
    cin >> n >> number;
    a.resize(n + 1);
    for(int i = 1; i <= n; i++) {
        cin >> a[i];
    }
    cout << b_find(number) << endl;
}
int main() {
    solve();
    return 0;
}

```

如果查找不小于number的第一个数，则写成对称形式


这个模板是开区间写法，比较容易理解

当然C++也有自带的二分查找的函数，最常见的是包含在`<algorithm>`头中的`binary_search`、`lower_bound`、`upper_bound`，其均要求待查找的容器/数组已排序（升序），操作区间左闭右开

`binary_search`只判断要查找的数是否在容器中存在

用法如下：
```cpp
binary_search(起始迭代器, 结束迭代器, 目标值);
//当然也可以自定义比较的规则
binary_search(起始迭代器, 结束迭代器, 目标值, 比较函数);
```

示例：
```cpp
#include <iostream>
#include <algorithm>
#include <vector>
using namespace std;
bool compare(int a, int b) {
    return a > b;
}
int main() {
    vector<int> a = {1, 2, 3, 4, 5, 6};
    cout << boolalpha << binary_search(a.begin(), a.end(), 5) << endl;
    cout << boolalpha << binary_search(a.begin(), a.end(), 7) << endl;
    cout << boolalpha << binary_search(a.crbegin(), a.crend(), 3, compare) << endl;
    return 0;
}
```

`lower_bound`会返回第一个大于等于目标的值的位置，而`upper_bound`会返回第一个大于目标的值的位置

用法：
```cpp
lower_bound(起始迭代器, 结束迭代器, 目标值);
upper_bound(起始迭代器, 结束迭代器, 目标值);
```

示例：
```cpp
//统计某一数字出现的次数
#include <iostream>
#include <algorithm>
#include <vector>
using namespace std;
int main() {
    vector<int> a = {1, 2, 3, 4, 5, 5, 5, 5, 6, 7};
    vector<int>::iterator i = lower_bound(a.begin(), a.end(), 5);
    vector<int>::iterator j = upper_bound(a.begin(), a.end(), 5);
    cout << j - i << endl;
    return 0;
}
```
注意`lower_bound`以及`upper_bound`返回的均是迭代器

如果所有元素都小于目标值，则`lower_bound`会返回结束迭代器

如果所有元素都小于等于目标值，则`upper_bound`会返回结束迭代器
